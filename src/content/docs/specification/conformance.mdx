### Level 1: Core (REQUIRED for conformance)

- `id`, `type`, `created` frontmatter fields and a non-empty Markdown body
  (projected as the `content` property in JSON-LD; see [Memory Unit](/specification/data-model/#memory-unit))
- Valid Markdown or JSON-LD structure
- Standard markdown-link relationship syntax

### Level 2: Standard (RECOMMENDED)

- All Level 1 requirements
- Namespace support
- Entity references
- Relationship types
- Temporal metadata (timestamps)

### Level 3: Full (OPTIONAL)

- All Level 2 requirements
- Bi-temporal model
- Decay functions
- Optional W3C-PROV-aligned provenance layer
- Embedding references
- Citations with rich metadata
- Compression support
- Extension support

### Conformance Statement

Implementations SHOULD declare their conformance level:

```yaml
# .mif/config.yaml
mif_version: "1.0.0"
conformance_level: 2
extensions:
  - subcog
  - custom-provider
```
